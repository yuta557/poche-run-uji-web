# POCHÉ RUN UJI

かべの中を、歩いてみよう。

宇治の たてものの「かべの中」を 歩く、スマホむけの ゲームです。
黒く ぬられた かべ（ポシェ）が 通り道。光の つぶを 全部 拾うと クリア。

- 練習 → 1. 宇治上神社 → 2. 京阪宇治駅 → 3. 平等院ミュージアム鳳翔館
- 遊ぶ： https://yuta557.github.io/poche-run-uji-web/

このリポジトリには **できあがった `index.html` だけ**が入っています。
迷路のデータ、Blender の 3Dモデル、絵をつくる道具などの ソースは べつのところにあります。

たてものの 絵・地図は すべて イメージです。
